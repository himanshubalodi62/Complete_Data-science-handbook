troubleshooting of controlplane

first check all nodes health
kubectl get nodes

check all pods running in cluster
kubectl get pods

check services
service kubelet status

to check proxy status
service kube-proxy status

to check logs of the pods
kubectl logs kube-apiserver-master -n kube-system


sudo jounalctl -u kube-apiserver


default directory of kube server
cat /etc/systemd/system/kubelet.service.d/10-kubeadm.conf

To check kubelet process
ps -ef | grep -i kubelet


To check status of kubelet service
systemctl status kubelet.service

To restart kubelet service
systemctl restart kubelet.service



To install weave

kubectl apply -f "https://cloud.weave.works/k8s/net?k8s-version=$(kubectl version | base64 | tr -d '\n')"

To install flannel
kubectl apply -f               https://raw.githubusercontent.com/coreos/flannel/2140ac876ef134e0ed5af15c65e414cf26827915/Documentation/kube-flannel.yml

To install calico
curl https://docs.projectcalico.org/manifests/calico.yaml -O

kubectl apply -f calico.yaml
