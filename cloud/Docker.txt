what is a container?

- Executable unit of software
 * Encapsulates everything necessary to run
 * Can be Run anywhere
- OS- Level virtualization 
 * Isolates processes
 * Controls resources allocated to those processes
- small, fast and protable
 * Doesn't include a guest os in every instance
 * leverages host OS

Container introduce in 2013(docker as  modern container)

Benefits of containers
 1- lightweight
	* don't include a guest OS
	* Spin you quickly and scale horizontally
2- Portable and platform Independent
3- Support modern Development and architecture
4- Improve utilization 
	* Scale each component individually

***Volume***
1) Volume is simply a directory inside our containers
2) Firstly, we have to declare this directory
as volume and than share volume.
3) Volume will be created in one container
4) You can declare a directory as volume only while creating container.
5) You can't create volume from existing container.
6) You can share one volume across any number of containers.
7) Volume will not be included when you update and image.

**You can mapped volue in two ways
 container <--> container
 Host <--> container

Benefits of volume
1) Decoupling container from storage.
2) share volume among different containers.
3) attach volume to containers.
4) On deleting container volume does not delete.
  


 

docker run -it --name container2 --privileged=true --volume-from container1 ubuntu /bin/bash
