to stablish communication among pods we create bridge. we have linux bridge and open vSwitch bridge.


to create linux bridge
ip link add <v-net-0> type bridge

to take bridge up
ip link set dev <v-net-0> up

to delete cable between namespaces
ip -n red link del veth-red

to create ethernet for bridge
ip link add veth-red type with peer name <veth-red-br>


to connect ethernet for to namespaces
ip link set veth-red netns red

to connect ethernet with bridge
ip link set <veth-red-br> master <v-net-0>

to add ip address
ip -n red addr add 192.168.15.1/24 dev veth-red

to up the devices 
ip -n red link set veth-red up

to assign to ip to bridge network
ip addr add 192.168.15.5/24 v-net-0


to add gateway in routing table 
ip netns exec blue ip route add 192.168.1.0/24 via 192.168.15.5


if you are not getting ping reply it could be no nat gateway available

to create nat gateway
iptables -t nat -A POSTROUTING -s 192.168.15.0/24 -j MASQUERADE

if you are not able to connect internet the you need to add a default gateway
ip netns exec <namespasename> ip route add default vai 192.168.15.5


to ping from a namespaces
ip netns exec <namespacename> ping 8.8.8.8

if you want to make communication with other private network

use portforwording and add it in routing table
to enable port forwording
iptables -t nat -A PREROUTING --dport 80 --to-destination 192.168.15.2:80 -j DNAT
