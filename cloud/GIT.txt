Git Stashing
stash is a temperory storage.
You can move your code in stash storage for
temperory, so you can empty your workspace so 
you can start new work, without completing perivous file.


To stash an item
git stash

To See stashed items list
git stash list

To apply stashe items
git stash apply stash@{number of file}

To clear the stash file
git stash clear


Git reset 
git reset is powerful command that is used to
undo local changes to the state of a git repo.


to reset staging area
git rest <filename>
git rest .

To reset the changes from both staging area and working directory
at a time.
git reset --hard


Git revert
Revert command helps you undp an existing commit.
=> It does not delete any data.
It create a new commit with included file reverted to their
previous state. 

git revert <commit-id>
