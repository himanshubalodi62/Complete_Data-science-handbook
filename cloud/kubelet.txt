the process to upgrade node

to drain any node
kubectl drain node-1

to undrain
kubectl uncordon node-1

to update kubeadm 
apt-get upgrade -y kubelet=1.22.0

to update kubelet
apt-get upgrade -y kubelet=1.12.0


to upgrade no configuration
kubeadm upgrade node config --kubelet- version v1.12

restart kubelete services 

systemctl restart kubelet
